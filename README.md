# Cocinum
Ce dépôt contient l’ensemble des fichiers, sources VHDL, scripts et projets Vivado réalisés dans le cadre du TP VHDL / FPGA. L’objectif du travail est d’apprendre à utiliser l’environnement Xilinx Vivado, de concevoir des modules logiques en VHDL, de les simuler, puis de les synthétiser pour une cible FPGA.
